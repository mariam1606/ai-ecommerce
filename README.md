AI E-Commerce Clothing Store

About the Project:

This project is an online clothing store built using Django and PostgreSQL.
Users can browse clothing products, search for products, filter products by category, view product details, add products to the shopping cart, update the cart, and place orders.
The project also includes a recommendation feature that helps users discover products based on their interactions with the store.

---------------------------------------------------
Features:

User Registration and Login
Browse Clothing Products
Product Details
Search Products
Filter Products by Category
Shopping Cart
Add and Remove Products from Cart
Update Cart Quantity
Checkout
Order History
Product Recommendations
Admin Product Management
Admin Order Management

---------------------------------------------------
Technologies Used:

Python
Django
PostgreSQL
HTML
CSS
JavaScript

---------------------------------------------------
Project Structure:

accounts: Handles user registration, login and profiles.
products: Handles clothing products and categories.
cart: Handles the shopping cart.
orders: Handles orders and checkout.
recommendations: Handles product recommendations.
config: Contains the main Django project settings.

---------------------------------------------------
How to Run the Project:

Install the required packages using the requirements.txt file.
Run the database migrations using python manage.py migrate.
Start the development server using python manage.py runserver.
Then open the website in your browser.

---------------------------------------------------
Database:

PostgreSQL is used to store users, products, categories, carts, orders, and product interactions.
